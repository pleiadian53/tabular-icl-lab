# tabular-icl-lab

Tutorials and write-ups for the lab. Planned:

- **What a prior-fitted network is.** In-context learning as amortized Bayesian inference: the synthetic prior, the training objective, and why one forward pass returns a predictive distribution.
- **Inside TabPFN.** The architecture (attention across features and across rows), how the context is encoded, and what changes between versions.
- **Applications.** One write-up per application in `examples/`, starting with genetic interactions in perturbation response.
